================================================================================
BACKUP & RECOVERY
================================================================================

Backup the database:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    pg_dump -U chirpstack chirpstack > backup.sql

Restore from backup:
  kubectl exec -i -n {{ .Release.Namespace }} postgres-0 -- \
    psql -U chirpstack chirpstack < backup.sql

For production, use automated backup tools:
  - Velero (cluster-wide snapshots)
  - pg_basebackup (continuous streaming WAL backup)
  - Cloud provider snapshots (AWS RDS, Azure Database, etc.)

================================================================================
SECURITY
================================================================================

Pod Security Context:
  - Run as User: 999 (postgres user)
  - FSGroup: 999
  - Privilege escalation: Disabled

Container Security:
  - Capabilities: All dropped
  - ReadOnlyRootFilesystem: Disabled (data directory needs write)

Production Recommendations:
  1. Change default password IMMEDIATELY
  2. Enable network policies to restrict access
  3. Use persistent volume backups
  4. Monitor database performance
  5. Set up audit logging
  6. Use encrypted connections (SSL/TLS)

Enable SSL/TLS connections:
  - Create certificates and mount as secrets
  - Set postgresql.conf parameters:
    ssl = on
    ssl_cert_file = '/etc/ssl/postgresql/server.crt'
    ssl_key_file = '/etc/ssl/postgresql/server.key'

================================================================================
TROUBLESHOOTING
================================================================================

Check pod status:
  kubectl get pods -n {{ .Release.Namespace }}

View logs:
  kubectl logs -n {{ .Release.Namespace }} -f postgres-0

Check if database is ready:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    pg_isready -U chirpstack

Test connection from another pod:
  kubectl run -it --rm psql --image=postgres:14-alpine --restart=Never -- \
    psql -h postgres.{{ .Release.Namespace }} -U chirpstack -d chirpstack -c "SELECT version();"

Check disk usage:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    df -h /var/lib/postgresql/data

Describe pod for events:
  kubectl describe pod -n {{ .Release.Namespace }} postgres-0

MAINTENANCE
================================================================================

Cleanup old data:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    vacuumdb -U chirpstack -d chirpstack -v -z

Analyze tables for query optimization:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    analyzedb -U chirpstack -d chirpstack

Check database size:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    psql -U chirpstack -d chirpstack -c "SELECT pg_size_pretty(pg_database_size('chirpstack'));"

View table sizes:
  kubectl exec -n {{ .Release.Namespace }} postgres-0 -- \
    psql -U chirpstack -d chirpstack -c "SELECT schemaname, tablename, pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) FROM pg_tables ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;"
