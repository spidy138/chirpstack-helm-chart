================================================================================
QUICK START
================================================================================

1. Check pod status:
   kubectl get pods -n {{ .Release.Namespace }}

2. View ChirpStack logs:
   kubectl logs -n {{ .Release.Namespace }} -f deployment/{{ .Release.Name }}-chirpstack

3. Port forward to access services:
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ .Release.Name }}-chirpstack 8080:8080
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ .Release.Name }}-rest-api 8090:8090

================================================================================
COMPONENT PORTS & ACCESS
================================================================================

ChirpStack Application Server:
  - Service: {{ .Release.Name }}-chirpstack
  - Port: 8080
  - Type: LoadBalancer
  - Access: kubectl port-forward svc/{{ .Release.Name }}-chirpstack 8080:8080

Gateway Bridge (Standard UDP):
  - Service: {{ .Release.Name }}-gateway-bridge
  - Port: 1700 (UDP)
  - Type: LoadBalancer
  - For: Standard LoRa gateways

Gateway Bridge Basic Station:
  - Service: {{ .Release.Name }}-gateway-bridge-basicstation
  - Port: 3001
  - Type: ClusterIP
  - For: Newer Basic Station protocol gateways

REST API:
  - Service: {{ .Release.Name }}-rest-api
  - Port: 8090
  - Type: ClusterIP
  - Access: kubectl port-forward svc/{{ .Release.Name }}-rest-api 8090:8090

================================================================================
SECURITY WARNINGS
================================================================================

⚠️  DEFAULT CREDENTIALS ARE SET - DO NOT USE IN PRODUCTION!

Change these immediately:
  1. PostgreSQL password: POSTGRESQL_PASSWORD
  2. Redis password: REDIS_PASSWORD
  3. API secret: API_SECRET
  4. MQTT certificates and keys

Update secrets:
  kubectl edit secret -n {{ .Release.Namespace }} chirpstack-secret
  kubectl edit secret -n {{ .Release.Namespace }} gateway-bridge-secret
  kubectl edit secret -n {{ .Release.Namespace }} gateway-bridge-basicstation-secret

TLS Configuration:
  - Certificates mounted at /etc/ssl/vernemq/
  - CA cert: /etc/ssl/vernemq/ca.crt
  - Client cert: /etc/ssl/vernemq/cert.crt
  - Client key: /etc/ssl/vernemq/key.key

================================================================================
GATEWAY CONFIGURATION
================================================================================

Standard Gateway Bridge (Port 1700):
  1. Get LoadBalancer IP:
     kubectl get svc -n {{ .Release.Namespace }} {{ .Release.Name }}-gateway-bridge

  2. Configure gateway to point to this IP on UDP port 1700

  3. Monitor logs:
     kubectl logs -f deployment/{{ .Release.Name }}-gateway-bridge

Topic Templates (configurable in values.yaml):
  Event: in865/gateway/{{ .GatewayID }}/event/{{ .EventType }}
  State: in865/gateway/{{ .GatewayID }}/state/{{ .StateType }}
  Command: in865/gateway/{{ .GatewayID }}/command/#

================================================================================
AUTOSCALING
================================================================================

Autoscaling is disabled by default. To enable:

  helm upgrade {{ .Release.Name }} ./chirpstack \
    --set chirpstack.autoscaling.enabled=true \
    --set chirpstack.autoscaling.maxReplicas=5

Ensure metrics-server is installed in your cluster.

================================================================================
TROUBLESHOOTING
================================================================================

Check pod status:
  kubectl get pods -n {{ .Release.Namespace }}

View logs:
  kubectl logs -n {{ .Release.Namespace }} -f deployment/{{ .Release.Name }}-chirpstack

Test database connection:
  kubectl run -it --rm debug --image=postgres:14-alpine \
    --restart=Never -- psql -h postgres.{{ .Release.Namespace }} \
    -U chirpstack -d chirpstack

Test Redis:
  kubectl run -it --rm debug --image=redis:7-alpine \
    --restart=Never -- redis-cli -h redis.{{ .Release.Namespace }} ping
